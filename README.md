# NexBoard – Real-Time Collaborative Whiteboard

## Overview

NexBoard is a full-stack real-time collaborative whiteboard platform that enables multiple users to work together simultaneously through a shared digital workspace. The platform supports real-time drawing synchronization, cursor tracking, and peer-to-peer audio/video communication, making it suitable for remote collaboration, brainstorming sessions, online teaching, and team discussions.

The application is built using the MERN Stack and leverages WebRTC and Socket.io to provide a seamless real-time collaborative experience.
